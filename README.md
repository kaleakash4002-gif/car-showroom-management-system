# 🚗 Car Showroom Management System

A Spring Boot based CRUD application for managing a car showroom.

---

## 📌 Features
- Add new cars
- Update car details
- Delete cars
- View all cars
- Customer management
- Booking system

---

## 🛠️ Tech Stack
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- MySQL
- JSP / HTML
- Maven

---

## 🚀 How to Run
1. Clone the repository
2. Import in Eclipse / IntelliJ
3. Configure MySQL database
4. Update application.properties
5. Run Spring Boot application
